## SponsorForm.jsx — old sponsorship form

**Replaced on 30/09/2026** by `src/components/Sponsorship.jsx`, which uses
Mercado Pago card subscriptions (see README, "Sponsorship").

It had been removed from the site because the plan was to do the sponsorship
through Pix Automático, which requires a CNPJ that has been active for at least
6 months. The card subscription has no such requirement, so the sponsorship
came back ahead of schedule.

The original file is not in this copy of the project; if it still exists on
the old machine, it can be discarded.

When the CNPJ reaches 6 months, it is worth re-evaluating Pix Automático as a
second option for the sponsorship (no card fee). See
`claude/plano-mercado-pago-repasse-de-taxa.md` in the project.
